# Parserdata + n8n: Google Drive Document Extraction

Automatically extract structured data from documents uploaded to Google Drive using **n8n** and the **Parserdata API**, then save clean JSON results back to Drive.

---

## What this workflow does

1. Watches a Google Drive folder
2. Downloads new files
3. Sends documents to Parserdata for AI extraction
4. Cleans the API response
5. Uploads extracted JSON back to Google Drive

No coding required.

---

## Requirements

- n8n (cloud or self-hosted)
- Google Drive account
- Parserdata API key
